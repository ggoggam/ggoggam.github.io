A command started in a shell is tied to that shell. Closing the shell can stop the command, even if it is running in the background.

```shell
# will exit when the shell is closed
$ sleep 100 &
[1] 12345
```

Use `nohup` to keep a background command running after you close the shell.

```shell
$ nohup sleep 100 &
[1] 12345
```

This is useful for jobs that take a while, such as model training. If you already started the command without it, suspend the command, resume it in the background, and remove it from the shell's job list:

```shell
$ sleep 100
^Z
shell: suspended   sleep 100
$ bg
[1] + continued   sleep 100
$ disown %1
```
